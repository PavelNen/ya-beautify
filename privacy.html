Яндекс Beautify

Privacy Policy

Last updated: April 2026

Ya Beautify does not collect, store, or transmit any personal data. Ever.

What the extension does

Ya Beautify is a browser extension that modifies the visual appearance of the Yandex homepage (ya.ru / yandex.ru) to make it cleaner and more minimalist. It hides distracting elements and reorganises the page layout entirely on your device.

Data collection

The extension does not:

  • Collect, read, or transmit any personal information
  • Track browsing history or search queries
  • Use cookies or local storage
  • Send any data to external servers
  • Communicate with any backend or analytics service

Network requests

The extension makes no network requests of its own. All assets (logo, icons) are bundled inside the extension package and loaded locally.

Permissions

The extension requests access only to the following pages:

  • ya.ru — Yandex home page
  • yandex.ru — Yandex home page

These permissions are used solely to inject CSS and JavaScript that restyle the page. No data is read or recorded.

Third-party services

Ya Beautify does not integrate with any third-party analytics, advertising, or tracking services.

Changes to this policy

If the extension is updated in a way that affects data handling, this page will be updated accordingly. The extension version and update date will be noted at the top of this page.

Contact

If you have any questions about this privacy policy, feel free to open an issue in the extension's repository or contact the developer directly.

Ya Beautify is an independent project and is not affiliated with Yandex LLC.
